# Simulator bots run on PyPy

On the simulator the bot is the speed limit, and its time goes to pure-Python hand search. PyPy (8.0.1, Python 3.12) plays the same games move for move and, once its JIT has warmed up over the first twenty or so games, runs the bot about 1.8 times as fast as CPython, so the supervisor launches simulator bots from `.venv-pypy` when that environment exists. Only the bot moves: Jackdaw ships a CPython-only wheel, so the simulator server stays in `.venv-jackdaw`, the two talk over HTTP as before, and running the simulator inside the bot's process is off the table while that holds. The live game, the supervisor and the control panel stay on CPython 3.13. The cost is that bot code must keep running on Python 3.12, and the PyPy environment pins `typer` 0.15.4 because newer releases need a compiled dependency PyPy has no build of. Setup is in [installation.md](../installation.md).

Superseded (2026-11-18): hand search and scoring moved into the compiled Rust kernel (`kernel/`), which loads on CPython only and runs the bot about twice as fast as PyPy did. The Python scorer and the PyPy launch were removed, so every bot runs on CPython from `.venv` and bot code no longer needs to stay valid on Python 3.12. Plan: [kernel-only](../plans/kernel-only.md).
